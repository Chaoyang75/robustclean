# 方法学说明

本文档说明 robustclean 背后的统计思想，方便你在论文方法学部分写清口径，
也方便你判断某个参数改动是否合理。

## 一、为什么不能只用一个检测器

任何单一检测器都隐含了对「异常」的一种定义，而定义一定会有盲区：

- **均值 ± 3σ**：均值和标准差由全部样本算出，异常值会自己把判据撑大。
  一个偏出 10σ 的极端值会把标准差抬高，结果它自己反而不被判为异常。
- **IQR**：只看单变量边缘分布，多变量组合异常（每个变量都正常、联合起来异常）必然漏检。
- **孤立森林**：擅长高维全局异常，对局部密度差异不敏感。
- **LOF**：反过来，对局部密度敏感，但当成簇的异常值出现时，它们彼此互为邻居，
  「局部密度」假设直接失效（本仓库基准里外来簇场景 F1 只有 0.030）。
- **马氏距离**：假设数据近似椭圆分布，遇到多峰或强非线性结构会失真。

盲区之间**不重叠**，这就是投票能提升稳健性的根据。

## 二、共识框架

### 1. 分数，而不是标签

每个检测器先输出连续的异常分数 $s_i(x)$，再各自定阈值给出标签。
阈值只用来投票，不用来做最终结论——最终结论由投票规则决定，这样口径唯一、可写进论文。

所有阈值都取「**稳健位置 + n × 稳健尺度**」的形式：

$$\text{cut} = \operatorname{median}(s) + n \cdot 1.4826 \cdot \operatorname{MAD}(s)$$

其中 $1.4826$ 是正态一致化常数，使 MAD 在正态下无偏估计标准差。
`n` 默认 3.5，与修正 Z 分数的经典取值一致。

### 2. 秩归一化：让每个检测器话语权相等

不同方法的分数尺度差异极大（马氏距离可以到几十，LOF 只在 1 附近），
直接平均会被大尺度方法绑架。因此先把每个方法的分数转成秩：

$$r_i = \frac{\operatorname{rank}(s_i) - 0.5}{n}$$

秩变换是单调的，不改变单个方法内部的排序，但抹平了尺度差异，并且对极端值免疫。

### 3. 加权投票

设第 $i$ 个检测器的标签为 $b_i(x)\in\{0,1\}$，权重 $w_i$（默认等权，$\sum w_i = 1$），则

$$V(x) = \sum_i w_i b_i(x), \qquad \hat{y}(x) = \mathbb{1}\big[V(x) \ge \tau\big]$$

$\tau$ 即 `vote_ratio`。默认 $\tau=0.5$（多数票）。
报告里会给出每个检测器的 $b_i$ 和最终的 $V(x)$，逐样本可查。

共识分数 $C(x) = \sum_i w_i r_i(x)$ 用于排序和敏感性展示，不直接决定去留。

## 三、各检测器的原理与阈值来源

| 检测器 | 异常分数的定义 | 阈值来源 |
| --- | --- | --- |
| MAD Z | $\lvert x - \operatorname{med}\rvert / (1.4826\,\mathrm{MAD})$，逐变量取最大 | 固定 3.5（经典修正 Z 分数） |
| IQR | 超出 $Q_1-1.5\mathrm{IQR}$ 或 $Q_3+1.5\mathrm{IQR}$ 的 IQR 倍数 | Tukey 准则 |
| Hampel | 滑动窗口内的 MAD Z | 固定 3.0 |
| 马氏距离 | $\sqrt{(x-\mu)^\top \Sigma^{-1} (x-\mu)}$，$\mu,\Sigma$ 由 MCD 稳健估计（覆盖 75% 样本） | 卡方分布 $\chi^2_d(0.975)$ |
| PCA/SVD | 稳健标准化后，保留 95% 方差的主成分的重构残差平方和 | 残差自身的 median + 3.5×MAD |
| kNN | 前 k 个近邻的平均距离（k=10） | 同上 |
| LOF | 局部可达密度比（k=20） | 同上 |
| 孤立森林 | $-$平均路径长度的分数（300 棵树，固定种子） | 同上 |
| DBSCAN | 噪声点标记；分数为到最近核心点的距离 | eps 由 k-距离曲线的 90% 分位点自动确定 |
| GMM | 负对数似然（EM，分量数由 BIC 在 1–4 之间选择） | 同上 |

用「median + n×MAD」而不是分位数或正态分位数来定阈值，是因为它不预设分布形状，
且对分数自身的极端值免疫。代价是难以给出精确的显著性水平——所以论文里写的是
「判定规则」，而不是「显著性检验」。

## 四、分组检测

实验数据常常有多个处理组，各组均值、方差甚至量纲都不同。
此时用全样本统一判定，量纲大的组会被整组判为异常。
`group_column` 参数会把检测限制在组内进行：同一组内比较，跨组不比较。
共识分数因此是**组内秩**，只在组内有可比性。

## 五、敏感性分析怎么写

审稿人关心的不是「你用了什么方法」，而是「结论会不会因为删数据而改变」。报告给出：

- 每个变量的剔除点数、剔除前后均值、标准差、偏度；
- 若均值变化超过 5%，说明结果对该变量敏感，建议改用 `winsorize` 保留样本量；
- 若标准差显著下降且偏度绝对值下降，说明剔除的主要是把分布拖歪的极端点，属于合理操作。

建议在论文中同时报告：**剔除前后的样本量、剔除比例、以及主要结论在这两种数据上是否一致**。
如果结论一致，说明处理方式是稳健的；如果不一致，那本身就是需要讨论的发现。

## 六、可复现性清单

`audit.json` 里记录了写论文所需的全部信息：

- 软件版本、Python 版本、生成时间
- 启用的检测器及**每个检测器的实际参数**
- 随机种子（孤立森林与高斯混合模型均为固定种子，结果确定可复现）
- 参与检测的变量、剔除的样本数、缺失值填补数量
- 哪些检测器因为什么原因被跳过
