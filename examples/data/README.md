# 示例数据来源

`penguins_size.csv` 来自 **palmerpenguins** 数据集（Gorman KB, Williams TD, Fraser WR, 2014），
以 **CC0 1.0（公有领域）** 发布，可自由使用与再分发。

- 原始数据：https://allisonhorst.github.io/palmerpenguins/
- 内容：344 只企鹅、3 个物种、4 个形态指标（喙长、喙深、鳍长、体重）
- 缺失值：以 `NA` 表示，共 8 个，其中 2 行为整行缺失

用它做示例的原因是：**不同物种的体型量级本来就不同**，能直接说明「分组检测」的必要性。
